# ⚖️ BMI Calculator (เครื่องคำนวณดัชนีมวลกาย)

เว็บแอปพลิเคชันคำนวณดัชนีมวลกาย (Body Mass Index - BMI) ที่ทันสมัย ใช้งานง่าย พร้อมแถบแสดงผลเกจสี และการวิเคราะห์คำแนะนำสุขภาพตามเกณฑ์มาตรฐานเอเชีย (WHO Asia-Pacific / กรมอนามัย กระทรวงสาธารณสุข)

---

## ✨ ฟีเจอร์หลัก (Key Features)

- 📏 **รองรับ 2 ระบบหน่วยวัด:**
  - **ระบบเมตริก (Metric):** เซนติเมตร (cm) และกิโลกรัม (kg)
  - **ระบบอิมพีเรียล (Imperial):** ฟุต & นิ้ว (ft, in) และปอนด์ (lbs)
  - มีระบบคำนวณแปลงค่าอัตโนมัติเมื่อสลับหน่วย
- 📊 **เกจวัดระดับ BMI แบบไดนามิก:** แสดงตำแหน่งเข็มชี้วัดตามระดับความเสี่ยง
- 🎯 **คำนวณช่วงน้ำหนักมาตรฐาน (Ideal Weight):** ระบุน้ำหนักที่เหมาะสมตามส่วนสูงของผู้ใช้งาน
- 💡 **คำแนะนำด้านสุขภาพเฉพาะบุคคล:** แนะนำแนวทางการปรับโภชนาการและการออกกำลังกายตามผลประเมิน
- 📝 **ระบบบันทึกประวัติการคำนวณล่าสุด (History):** จัดเก็บข้อมูลใน LocalStorage สูงสุด 5 รายการล่าสุด
- 📱 **การออกแบบ Responsive:** รองรับการใช้งานทั้งบนมือถือ แท็บเล็ต และคอมพิวเตอร์
- ⚡ **Zero Dependencies:** รันได้ทันทีโดยไม่ต้องติดตั้งไลบรารีภายนอก

## 📐 เกณฑ์การประเมินค่า BMI (เกณฑ์สำหรับคนเอเชีย)

$$BMI = \frac{\text{น้ำหนัก (kg)}}{(\text{ส่วนสูง (m)})^2}$$

| ระดับ BMI (kg/m²) | เกณฑ์ความหมาย | ความเสี่ยงต่อสุขภาพ |
| :--- | :--- | :--- |
| **น้อยกว่า 18.5** | ผอมเกินไป (Underweight) | เสี่ยงต่อภาวะขาดสารอาหาร |
| **18.5 - 22.9** | สมส่วน / สุขภาพดี (Normal) | ความเสี่ยงปกติ สุขภาพดี |
| **23.0 - 24.9** | น้ำหนักเกิน / ท้วม (Overweight) | เริ่มเสี่ยงต่อโรคหัวใจและเบาหวาน |
| **25.0 - 29.9** | โรคอ้วนระดับ 1 (Obesity Grade 1) | เสี่ยงปานกลาง ควรควบคุมอาหาร |
| **30.0 ขึ้นไป** | โรคอ้วนระดับ 2 (Obesity Grade 2) | เสี่ยงสูงมาก ควรปรึกษาแพทย์ |

## 🚀 วิธีเปิดใช้งาน (Getting Started)

### วิธีที่ 1: เปิดผ่านเบราว์เซอร์โดยตรง
เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ (Chrome, Edge, Safari, Firefox)

### วิธีที่ 2: รันผ่าน Node.js
```bash
# เริ่มต้นเซิร์ฟเวอร์
npm start
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:3000`
